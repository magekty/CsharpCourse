01 · 한 줄 개요와 소재 선정 이유

지상 골드를 비용으로 지불해 광산에 내려가 광물을 캐고, 지상으로 복귀해야 가방 속 미정산 광물이 골드로 확정된다. 붕괴가 일어나면 기적 생존(가방 50% 유지 후 계속 진행), 얕은 층 구조, 심층 매몰의 3단계 패널티가 적용된다. 목표 골드를 달성할 때마다 초급부터 그랜드마스터까지 승급하며, 모든 등급을 돌파하면 무한(Endless) 모드와 다차원 심연 공간이 열린다.

"심층 채굴 & 복귀 정산"은 한 턴의 선택이 [1] 더 깊이 채굴 / [2] 지상 복귀(정산) / [0] 종료 3개뿐이지만, 지상 보관 골드(확정 자산)와 가방 속 미정산 광물(위험 자산)이 분리되어 매 턴 "지금 안전하게 정산할 것인가, 보상 점핑 층과 대박 광맥을 노리고 한 층 더 내려갈 것인가"의 판단을 요구한다. 짧은 5분 템포로 초급 등급을 돌파할 수 있고, 이후 승급과 다차원 확장을 통해 무한한 도전 동기를 제공한다.

결론 — 매 턴 화면 구성

파산 조건(지상 골드 < 20 이고 가방 == 0)에 도달하거나 [0] 종료를 선택하면 ⑥ 메뉴 대신 최종 결과 메시지가 출력되고 반복이 종료된다.

03 · 채굴 → 복귀 정산 → 종료 반복 흐름

한 턴은 항상 동일한 파이프라인을 순환한다. 목표 골드 달성은 게임을 즉시 종료시키지 않고 자동 승급 후 다음 목표를 갱신하여 무한(Endless) 플레이로 이어진다.

[1] 더 깊이 채굴을 고르면

  1. 비용 확인: 지상 골드가 다음 층 진입비보다 적으면 진입 불가 — 안내 메시지만 바꾸고 턴을 유지한다(가방에 광물이 있다면 복귀해서 정산해야 함).
  2. 진입비 선지불: 지상 골드에서 진입비를 차감하고 다음 층(depth + 1)으로 내려간다.
  3. 성공 판정: 0~99 난수가 성공 확률 미만이면 채굴 성공 → 기본 보상에 구간 점핑 배율과 대박 광맥(10% 확률, 2.5배)을 계산해 가방(미정산)에 누적한다.
  4. 붕괴 판정(실패 시 3단계 분기):
    • 기적의 구사일생(15% 확률): 강제 복귀 면제! 가방 가치의 50%만 유실되고 현재 층에 살아남아 다음 턴에 계속 내려갈지 복귀할지 선택할 수 있다.
    • 얕은 층 구조(1~3층, 기적 실패 시): 입구 인근이라 구조대가 즉시 회수. 가방의 30%는 회수 정산(70% 유실)되고, 지상 골드에서 치료비 30 G를 지불한 뒤 지상(0층)으로 강제 복귀한다.
    • 심층·다차원 매몰(4층 이상, 기적 실패 시): 가방 광물 100% 전액 소실 + 지상 골드에서 긴급 구조비(지상 골드의 25%, 최소 50 G)를 지불한 뒤 지상(0층)으로 강제 복귀한다.

[2] 지상 복귀(정산)를 고르면

  1. 지상(0층) 상태 예외 처리: 이미 지상에 있다면 정산할 탐험이 없으므로 "이미 지상에 있습니다. [1]번을 눌러 광산에 진입하세요." 안내 메시지를 띄우고 게임을 그대로 이어간다.
  2. 정상 복귀 및 정산: 지하(1층 이상)에서 복귀하면 가방 속 미정산 광물 전액이 지상 골드로 입금되고, 가방은 0 G, 깊이는 0층으로 초기화된다.
  3. 승급 및 무한 모드 체크: 정산 후 지상 골드가 현재 등급의 목표 골드 이상이면 즉시 다음 등급으로 승급하고 새로운 목표 금액이 설정된다(단일 턴에 여러 등급을 뛰어넘는 대박 정산 시 연속 승급).

[0] 종료를 고르면

running = false로 변경하여 다음 루프 검사에서 자연스럽게 게임을 마치고 최종 도달 등급과 최고 자산을 요약해 보여준다.
