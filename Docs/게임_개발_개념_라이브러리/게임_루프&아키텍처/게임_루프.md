# 게임루프
    - 게임 루프란 입력이 있든 없든 게임이 실행중일때 지속적으로 실행되는것 입니다.

## 무엇을
    - 게임 루프를 입력, 갱신, 렌더링을 프레임 (한 바퀴)로 표현한 것이다.

    - 입력은 이벤트로 만들어줘
    - 갱신은 delta time 표현하도록 구성해라
    - 화면을 그려줘(render)
