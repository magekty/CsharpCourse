# C# 실습 문제 풀이 및 리마인드 정리

- 수업 자료를 바탕으로 오늘 푼 실습 문제들의 해결 과정과 리마인드된 부분을 간결하게 정리합니다.

  1> 오늘 짚어본 핵심 개념 및 실수 포인트
- [! (Null 면제 연산자)]: `Console.ReadLine()`의 `string?` 경고를 줄여주지만 런타임 검증은 못 하므로, 안전한 숫자 변환에는 `int.TryParse`가 적합합니다.
- [if vs switch]: `if`는 위에서부터 참인 첫 분기만 실행하며, 대상 값 분기나 가독성·패턴 매칭에서는 `switch`가 유리합니다.
- [최댓값 갱신]: `0` 기준이나 불필요한 중간 출력을 피하고 `int.MinValue`로 시작해 `foreach`에서 더 큰 값만 갱신하는 방식이 깔끔합니다.
- [메서드 반환 및 멤버 대입]: `bool` 메서드는 모든 경로에서 값을 반환해야 하며, 생성자에서는 매개변수와 프로퍼티(`Price = price`)를 구분해 대입해야 합니다.
- [조건식 & Dictionary 조회]: 논리 연산자(`&&`, `||`) 모순을 피하고, `int.TryParse`와 `TryGetValue` 반환값으로 없는 키나 잘못된 입력을 처리합니다.

  2> 오늘 해결한 핵심 코드 요약
- 조건 검증, 최댓값 탐색, 클래스 프로퍼티 할당, 딕셔너리 조회 및 예외 입력 처리를 간결하게 구현했습니다.

```csharp
// 최댓값 구하기
int max = int.MinValue;
foreach (int score in scores)
    if (score > max) max = score;

// 조건 반환 및 프로퍼티 대입
static bool IsPassed(int score) => score >= 60;

class Product
{
    public string Name { get; }
    public int Price { get; }
    public Product(string name, int price) { Name = name; Price = price; }
}

// 입력 검증 및 Dictionary 조회
if (!int.TryParse(Console.ReadLine(), out int number) || !students.TryGetValue(number, out string? name))
    Console.WriteLine("없음");
else
    Console.WriteLine(name);
```

- 잘 기억난 부분: [기본 제어문 흐름, `foreach` 순회, 클래스와 프로퍼티 구조]
